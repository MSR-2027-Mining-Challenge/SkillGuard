## 6. Limitations and incomplete results
- **No security alert has been validated by a human yet.** All 55 distinct alert locations are Cisco scanner output; none of them is a confirmed vulnerability.
- 15 configuration(s) were excluded by design: GitSkills did not store every supporting file of 0 skill(s), so their full-folder scans were not run. Those skills drop out of the SKILL.md-only vs full-folder comparison.
- 62 partial and 0 contract-only scan(s) are kept but excluded from the primary analysis (see the status definitions); their findings appear only as preliminary / sensitivity evidence.
- Most finding rows (285 of 506) are metadata-quality notes (missing license, vague description, ...), not security alerts. "Skills with findings" therefore overstates security exposure; use skills with security alerts (29).
- Configurations using `behavioral_llm` are not deterministic: Behavioral baseline plus Cisco's LLM Analyzer (--use-llm): one LLM call per scan over SKILL.md, manifest, code and referenced files within Cisco's prompt budgets, enriched with the deterministic findings. Static/behavioral findings are unchanged; LLM findings carry analyzer 'llm'. Results depend on the model recorded in run_metadata.json.
- Configurations using `behavioral_llm_meta` are not deterministic: B plus the Meta-Analyzer over all findings, including the LLM Analyzer's. The LLM Analyzer runs again inside this scan, so its findings can differ from B's (see llm_run_stability).
- Configurations using `behavioral_meta` are not deterministic: Behavioral baseline plus Cisco's Meta-Analyzer (--enable-meta) without the LLM Analyzer. Meta post-processes the deterministic findings: it is skipped when there are none, makes no LLM call when every finding is clear deterministic evidence, and otherwise marks findings as false positives (kept here via --verbose) or adds 'missed threats'. It never changes severity.
- Snippets and other text from skills are redacted where they look like secrets, and absolute local paths are rewritten as repository-relative ones. Cisco's raw reports (local only, not committed) keep the original text.
