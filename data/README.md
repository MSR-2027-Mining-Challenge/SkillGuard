# Data

The GitSkills database is **not committed**. Download the official sample (`agent_skills_sample.zip`, about 277 MB unzipped) as described in the main [README](../README.md#2-get-the-database), and place it at:

```
data/sample/agent_skills_sample.db
```

All results in this repository were produced with a file whose SHA-256 starts with `683888c9`. `*.db` files and `data/sample/*.zip` are git-ignored.
